ImagEngine

High-performance edge image optimization and transformation proxy running on Cloudflare Pages Functions.

API Endpoints

  • /health - Health status check
  • /[tenant]/path/to/image.jpg - Image proxy
  • /[tenant]/path/to/image.jpg?w=600&format=webp - Resize & convert
  • /[tenant]/path/to/image-jpg.webp - Slug-based format conversion
