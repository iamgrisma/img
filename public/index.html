1. URL Syntax & Routing

ImagEngine supports both Slug-based and Query Parameter based routing:

Pattern A: Slug-based Extension URL (Recommended for SEO & Clean URLs)
https://<domain>/[subdomain.]<tenant>/<path>-<origExt>.<targetExt>[?params]
Pattern B: Dot Slug URL
https://<domain>/[subdomain.]<tenant>/<path>.<origExt>.<targetExt>[?params]
Pattern C: Direct Path with Format Query Parameter
https://<domain>/[subdomain.]<tenant>/<path>.<origExt>[?format=<targetExt>&params]

3. Production Scenarios & Examples

Scenario 01

Social Media OG Image (SVG → WebP at 1200x630)

Render dynamic Open Graph SVG cards into crisp WebP for Facebook, Viber, and Twitter crawlers.

GET /objects.tn/wp-content/uploads/2026/10/banner-svg.webp?w=1200&h=630&fit=cover

Under the hood: Vector graphics and fonts are rasterized into pixel-perfect WebP at q=85 (~35KB output) and globally cached for 1 year.

Scenario 02

Candidate & Profile Avatar (Square Crop Anchored to Face)

Generate 256x256 square avatars anchored to the top so heads and faces are never chopped off.

# Quick avatar preset:
GET /ecn/candidates/kamal-png.webp?avatar=1

# Or custom avatar dimensions:
GET /ecn/candidates/kamal-png.webp?w=300&h=300&fit=cover&position=top
Scenario 03

Proportional Aspect-Ratio Resizing (Single Dimension)

Supply either width or height alone; ImagEngine automatically calculates the other dimension maintaining exact aspect ratio without distortion.

# Resize to 500px width (auto height):
GET /object.gcom/uploads/photo.jpg?w=500&format=webp

# Resize to 400px height (auto width):
GET /object.gcom/uploads/photo.jpg?h=400&format=webp
Scenario 04

Fit Modes: 600x600 from a 1000x1120 Portrait Photo

Control exact cropping and fitting behavior when providing both width and height:

Fit Parameter Behavior Example URL
fit=cover Recommended: Crops excess edges to fill the exact 600x600 box without stretching. ?w=600&h=600&fit=cover
fit=contain Preserves full image within 600x600 bounds (aspect ratio preserved, no cropping). ?w=600&h=600&fit=contain
fit=fill Forces image to fill 600x600, stretching/distorting if aspect ratio differs. ?w=600&h=600&fit=fill
fit=inside Scales down to be as large as possible while staying completely within dimensions. ?w=600&h=600&fit=inside
Scenario 05

Crop Alignment (Position Anchoring)

When cropping with fit=cover, control which part of the image is kept:

?w=600&h=600&fit=cover&position=center   # Default: center crop
?w=600&h=600&fit=cover&position=top      # Top anchor (perfect for portraits)
?w=600&h=600&fit=cover&position=bottom   # Bottom anchor
?w=600&h=600&fit=cover&position=left     # Left anchor
?w=600&h=600&fit=cover&position=right    # Right anchor
Scenario 06

Format Transformations & Passthrough

Source Target Behavior
SVG WebP Renders crisp vector to raster at target size, encodes to lightweight WebP.
SVG PNG Direct rasterization into lossless PNG format.
SVG SVG Untouched Stream: Returns pristine SVG directly with 1-year cache.
JPEG WebP Decodes JPEG, applies transforms, encodes to lightweight WebP.
PNG WebP Compresses heavy PNG to WebP with up to 85% bandwidth reduction.
WebP WebP No transform → direct stream. If resized → re-encoded to target dimensions.
Scenario 07

Rotation, Grayscale & Creative Filters

Comprehensive image transformation capabilities:

# Quality tuning (1 to 100, default 85):
GET /object.gcom/photo-jpg.webp?q=92   # High quality photography
GET /object.gcom/photo-jpg.webp?q=60   # Mobile lightweight preview

# Rotation & Mirror Flipping:
GET /object.gcom/photo-jpg.webp?rotate=90   # Rotate 90 degrees
GET /object.gcom/photo-jpg.webp?flip=h      # Horizontal mirror flip
GET /object.gcom/photo-jpg.webp?flop=1      # Vertical flip

# Color & Creative Filters:
GET /object.gcom/photo-jpg.webp?grayscale=1       # Human-eye corrected black & white
GET /object.gcom/photo-jpg.webp?w=800&blur=6      # Gaussian blur (preview placeholders)
GET /object.gcom/photo-jpg.webp?w=800&sharpen=1   # Unsharp mask for high-detail graphics
Scenario 08

Multi-Tier Negative Caching & Edge Shield

Protection against quota drainage, broken links, and scanning bots:

  • Unauthorized & Random URLs: Dropped immediately at the global network edge before any server execution.
  • Missing Upstream Media: When an image does not exist on origin, the 404 response is negative-cached for 300 seconds (5 minutes) to absorb repeated hits.
Scenario 09

Auto-Healing Malformed Query Strings

Sometimes CMS themes, social scrapers, or third-party links concatenate query parameters without standard ampersands (e.g. ?h=630w=450 instead of ?h=630&w=450).

# Broken URL from scraper:
GET /objects.tn/banner-webp.webp?h=630w=450

# Automatically normalized internally to:
GET /objects.tn/banner-webp.webp?h=630&w=450  → Exact 450x630 output!
